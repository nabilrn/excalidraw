PRODUCT + DESIGN DOCUMENTATION

A focused desktop workspace that feels drawn by hand, not decorated by hand.

FocusCanvas combines tasks, focus sessions, a handwritten completion calendar, and Excalidraw canvases inside a compact local-first Windows app. The visual system keeps professional desktop structure while allowing small human imperfections.

01 — PRODUCT

One workspace, two modes.

Tasks answer what should I finish? Canvases answer what do I need to think through? The focus rail stays visible so time remains part of the workspace instead of becoming a separate timer app.

TASKS

Plan, focus, mark the day.

Estimated minutes, active-task context, session history, and a monthly calendar. Finishing a task leaves a red marker on the date — a physical-calendar habit translated into software.

CANVASES

Every task gets a place to think.

Task-backed groups are created automatically. Manual groups remain available for loose ideas, and each canvas opens into the full Excalidraw editor.

02 — PRINCIPLES

Desktop discipline, sketchbook character.

01

Structure first

Panels, alignment, density, and hierarchy behave like a serious desktop tool. Handwriting never excuses weak layout.

02

Mostly monochrome

Black, white, and quiet grays carry almost everything. Color is reserved for semantic gestures such as the red completion marker.

03

Local is the default

The interface should remain useful without an account or network. Cloud sync is an optional recovery layer, not the identity of the product.

04

Imperfection with limits

Uneven radii, dashed rules, Caveat headings, and small scribbles add warmth. Controls still keep consistent hit areas and predictable behavior.

04 — COMPONENT PATTERNS

Small controls. Clear states.

The UI avoids inflated cards and oversized controls. Most actions live inside thin borders, compact rows, and short handwritten labels.

Buttons

Primary actions are black. Secondary actions are white with quiet borders. Text actions can drop the container entirely.
